## 0. 执行门禁

- **上游计划中多数 P0 已在 v2.4.x 落地**（用量去重重建、日志/代理安全边界、工具缺函数名处理，v2.4.5 起还有按模型协议探测路由），本版不重复实现，只补回归测试。

### 0.3 构建与测试边界

- 本机只允许：阅读/编辑代码、静态检索、`git diff`、`git status`、提交与推送。
- 本机禁止：`pnpm build`、`pnpm test:unit`、`cargo build/test/clippy`、`pnpm tauri build` 及任何安装包构建。
- 类型检查、单元测试、Rust 检查、跨平台构建、签名、打包与发布全部由 GitHub Actions 完成（沿用 v2.1.0 边界）。
- 候选包只能由手动触发的 candidate workflow 生成，不得直接创建正式 Release。

### 0.4 里程碑依赖与并行

- M1 是 M3 的硬前置（依赖升级先行）；M4 动工前须完成 TASK-000 的 v2.4.6 复核。
- M2、M5 与 M1 无依赖，可并行推进。
- M6 依赖 M1–M5 全部收口。
- 同一里程碑内任务可并行，但 M3 的 TASK-007/008（事务持久化与恢复）应先于 TASK-009～012 合并，避免新安装入口建立在不可恢复的事务上。
