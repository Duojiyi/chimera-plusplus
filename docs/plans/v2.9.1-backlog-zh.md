## 1. 安全与信任边界

- [ ] **P2 · 把 SQLite 升到 3.50.2 以上**（F-06）：2.9.0 只做了应用层缓解（SQL 导入的函数白名单、64 MiB 上限），捆绑的 SQLite 仍是 rusqlite 0.31 附带的 3.45.x。升级要换到 rusqlite 0.37 以上，API 有变化，影响所有数据库代码，需要整轮回归。
- [~] **P2 · 渲染层信任边界**（F-14、F-15、F-16、F-17、F-19、F-21）：
  - 2.9.0 已做：会话终端只接受固定格式的 resume 命令并删除了 `custom` 分支；会话读取限制在各工具的会话目录内；删除了 16 个前端没有调用的命令（含环境变量三件套和旧版深链导入）。
  - 剩余：为渲染层定义不含密钥的 DTO，保存改为 patch 语义（F-15）；Pi/OMP 插件安装由后端生成计划并弹原生确认框（F-16）；用 `tauri_build::Attributes::app_manifest` 给全部命令生成权限并在 capability 里逐个列出（F-17）；深链确认绑定后端待确认项的 ID，防重放（F-19）。
- [~] **P3 · 本地代理令牌**（F-02）：2.9.0 已加随机令牌、Host 校验、并发与请求体上限。旧占位符 `PROXY_MANAGED` 在升级后 72 小时内继续接受，之后只认新令牌。剩余：把旧占位符完全移除；给手动配置本地代理的用户一个“不要求令牌”的设置开关（现在只能重新开启接管来写入令牌）。
- [~] **P2 · 发布签名私钥**（F-01）：2.9.0 做了 candidate 的 ref 限制和构建后清除私钥。剩余：独立的签名 job；candidate 改用测试密钥；给 `release` environment 配置分支/标签限制和必需审批人（GitHub 仓库设置，现在为空）。
- [ ] **P3 · 渲染进程调试端口**（F-07）：2.9.0 只去掉了固定端口回退。剩余：改用 `--remote-debugging-pipe`，或只在注入时短暂开启调试端口；加“关闭模型解锁”开关；Chimera 重启后复用仍在运行的 Codex 的端口（读 `DevToolsActivePort`）。
- [ ] **P3 · 凭据存储**（F-08）：xAI、Copilot、Codex OAuth 的托管令牌迁进 DPAPI vault；API Key 列加密；应用数据目录设置受保护 DACL。
- [ ] **P3 · 模型解锁脚本**（F-27）：只拦截已识别 transport 上记录过的请求，去掉全局 `JSON.parse` / `Response.json` 兜底，注入成功后停止轮询并提供卸载函数。
- [ ] **P3 · 退出时的状态目录**（F-38）：macOS 用 Warp 恢复会话时，脚本写在项目目录里（Warp 的 `path` 参数需要实机验证后才能改到临时目录）。2.9.0 只保证启动失败时删除脚本。
- [~] **P3 · panic 日志**（F-39）：2.9.0 去掉了全局 `RUST_BACKTRACE` 并给崩溃信息脱敏。剩余：`strip = "symbols"` 让 release 回溯没有符号，改为 `debuginfo` 前要先看安装包体积变化。

## 5. Claude 账号管理

2.8.10 先落地了账号总览（卡片 / 列表视图、搜索、筛选、排序、隐藏邮箱、刷新全部额度、备注）和分页签的添加账号对话框。对照 Cockpit Tools 还没做、留到下个大版本的：

- [ ] **P2 · 批量操作**：全选 / 多选后批量刷新、导出、停用、删除。
- [ ] **P2 · 标签与分组**：账号打标签，按标签筛选，分组页签。
- [ ] **P2 · 浏览器授权在界面里显示授权链接**：现在授权链接和授权码在弹出的控制台窗口里；改为在对话框里显示链接、可复制、可粘贴回调 / 授权码（需要自己实现 OAuth PKCE，不再依赖 `claude auth login`，也能让只装了 Desktop 的用户添加账号）。
- [ ] **P3 · 从其他切换工具的本机目录导入**（claude-swap、claude_switch 等），不用先导出文件。
- [ ] **P2 · 剩余三路盲审**：用量总览、前端、整体与产品的盲审在 2.8.10 发版前没有跑完（额度中断，按用户要求先发版）。

2.9.0 做了：凭证文件导入导出、浏览器授权、令牌与 API Key 账号、停用与排序、并行会话、目录绑定、用量总览、默认 Claude Desktop 登录快照切换。设计与取舍见 `docs/plans/claude-accounts-expansion-zh.md`。没做的：

- [ ] **P3 · 加密导出**：现在只有明文 JSON（导出前有醒目警告）。claude-swap 的 `encrypted` 格式用口令加密，导入侧遇到 `encrypted: true` 会拒绝并提示先解密；要支持就得连口令派生方式一起对齐。
- [ ] **P3 · 只导出选中的账号**：后端 `export_claude_logins` 已接受 `ids`，界面只有“全部导出”。
- [ ] **P3 · 并行会话与浏览器授权在 macOS / Linux**：现在仅 Windows（需要一个能粘贴授权码的控制台窗口、锁文件探测）；macOS 的保险库本来就不支持。
- [ ] **P3 · 目录绑定的 shell 集成**：现在只在从 Chimera 启动 Claude 时生效。要“cd 进去就换号”需要 shell 钩子或 PATH 里的启动器，侵入大，没做；用“复制启动命令”覆盖别的终端。
- [ ] **P3 · 并行会话的对话记录**：不复制，各账号各自一份；用量总览会把它们合并统计，但“恢复会话”看不到别的账号的对话。
- [ ] **P3 · 自动切换**（额度到阈值自动换号）：参考项目都有，这次没做，需要先定“何时安全地切”的规则。
- [ ] **Claude Desktop 令牌缓存写入**：没做，也不建议做：Desktop 的登录是 Cookie 加 `Local State` 里的密钥，缓存里的令牌属于 Desktop 自己的 OAuth 客户端，写进去换不了账号。要同时用多个账号用独立目录方案，要切换默认 Desktop 用登录快照。
- [ ] **P3 · 桌面快照在 macOS / Linux**：密钥在钥匙串 / libsecret，不在本版范围。
- [ ] **P3 · 同名来源合并**：用量总览按账号名称合并来源，两个账号同名会被算作一个。
- [ ] **P3 · 裸 `.credentials.json` 的账号识别**：没有 `oauthAccount` 的订阅登录只能靠访问令牌指纹识别，令牌刷新后可能被再存一份（现在导入时在报告里提醒）。可以导入时用访问令牌请求 `/api/oauth/profile` 补出邮箱和账号编号。
- [ ] **P3 · 孤儿进程占着会话锁**：`claude` 退出后留下的后台进程会继承锁句柄，账号一直显示“会话中”。需要在锁文件里记启动器进程号并检查是否还活着，或给一个“强制解除”按钮。
- [ ] **P3 · 默认 Desktop 的暂存区**：未归属的登录只能手动从 `desktop-auth/.stash` 取回；可以加列表和“保存为某账号的 Desktop 登录”。
- [ ] **P3 · 关闭 Desktop 前点名运行中的会话**：现在确认框只笼统说会结束 Code 会话和 MCP 服务；可以先查主进程下有没有 `claude-code` 目录里的 `claude.exe` 子进程，有就写出数量。
- [ ] **P3 · 并行会话启动的几个窄窗口**：从 `prepare_in` 到终端拿到锁文件约有一秒空窗，期间额度刷新或切换可能与会话抢同一个 refresh token（`open_claude_session` 没取 `account_lock`）；「复制启动命令」放久了再用，启动器不会重新检查账号状态；会话目录里的 `.claude.json` / `.credentials.json` 被写坏时 `prepare_in` 一直拒绝，界面没有恢复办法（应改为备份后重建）。
- [ ] **P3 · 第三方线路启用时账号切换不生效**：线路把 `ANTHROPIC_*` 写进同一个 `settings.json` 的 `env`，Claude Code 实际走线路而不是账号。账号卡片应在当前线路不是官方线路时提示“现在用的是线路『xxx』”。
- [ ] **P3 · 「用此账号登录 Desktop」**：没有 Desktop 快照的账号现在要手动在 Desktop 里登录再保存；claude_switch 的做法是关掉 Desktop、归档当前登录、把登录相关文件清到登录页，登录后自动归属。
- [ ] **P3 · 非 Windows 的说明**：macOS 上 Desktop 页整块新功能静默消失，没有一句原因。
- [ ] **P3 · 无障碍补完**：用量卡的范围选择和分组切换是 `radiogroup` / `tablist` 但没有方向键和 tabpanel，改成 `aria-pressed` 按钮；行内禁用按钮的原因（`title` 在 `pointer-events: none` 下不显示）改成可见文字；错误和“请手动复制”的提示不要只放在 4 秒的 toast 里。
- [ ] **P3 · 用量扫描跟随符号链接**：现在项目目录或日志文件是链接就跳过（只计数并在界面写出），现有导入会跟随。
- [ ] **P3 · 令牌账号「更新令牌」**：相同指纹被拒绝，换新令牌只能再加一个账号，原账号上的目录绑定因为没有邮箱找不回，要手动重绑。
- [ ] **P3 · 两个保险库账号同一个账号编号**（同一人的个人版和团队版）：Desktop 认人只返回第一个，第二个没有 Desktop 入口。
- [ ] **P3 · 切换期间锁住 Desktop 单实例文件**：现在只在应用快照前后各检查一次，期间被开机自启或协议回调拉起的 Desktop 会让这次切换走失败还原。
