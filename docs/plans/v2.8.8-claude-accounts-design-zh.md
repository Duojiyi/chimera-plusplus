# Claude 多账号与账号隔离 — 设计稿（2.8.8）

> 编写日期：2026-10-30　状态：执行中
> 需求（用户 10-30）：参考 `D:\Desktop\Claude account`（生态调研 + `ccp.ps1`/`ccx.ps1` + `claude-switcher-refs` 下 10 个开源项目），为 Claude Code 与 Claude Desktop 增加多账号管理、账号隔离（"指纹隔离"）。

## 1. 结论与边界

生态里只有四种做法：换凭据、独立配置目录、本地代理池、沙箱。我们采用**独立配置目录**（参考调研第 0、3 节与 claude-code-account-switcher 的 Desktop 方案）：

- **Claude Code**：每个账号一个 `CLAUDE_CONFIG_DIR`。凭据（`.credentials.json`）、`.claude.json`、会话、设置、MCP 全部在该目录里，账号之间互不可见。
- **Claude Desktop**：每个账号一个 Chromium `--user-data-dir`。登录态、设置、MCP 互相独立，**多个账号可以同时开着**。
- **"指纹隔离"的含义**：每个账号的本地身份数据（客户端生成的设备/会话标识、缓存、登录态）只存在于它自己的目录里，账号之间不共享、不串号。参考项目里的 "fingerprint" 指用令牌短哈希识别"当前登录的是哪个号"，我们同样用它做状态展示。

**不做**（会越过平台账号政策，也和我们"不向第三方注入托管账号令牌"的边界冲突）：伪造或随机化硬件/设备标识、为规避风控给账号挂独立出口、多账号令牌池轮换以叠加额度（调研里的"C 派代理池"）。

选择独立目录而不是"换凭据"的理由：
1. 不复制、不搬运任何令牌，Chimera 只读非机密元数据（邮箱、套餐、令牌短哈希）。
2. 没有"换号后正在运行的进程把旧令牌写回"的竞态（调研第 1 节第 5 点）。
3. 主账号（`~/.claude`、Claude Desktop 默认目录）完全不动；删除 Chimera 的账号目录也不影响它。

## 2. 存储

- 根目录：Chimera 数据目录下 `claude-accounts/`，每个账号 `claude-accounts/<id>/`：
  - `code/`：该账号的 `CLAUDE_CONFIG_DIR`
  - `desktop/`：该账号的 Claude Desktop `--user-data-dir`
  - `account.json`：`{ id, name, createdAt }`（只有显示名，不存凭据）
- `<id>`：小写字母数字与 `-`，创建时生成，与显示名无关；路径一律由 id 拼出并校验仍在根目录内。
- 主账号不出现在根目录里，列表中单独显示为「默认账号（~/.claude / 系统默认目录）」，只读展示。

## 3. 后端（Rust）

新模块 `src-tauri/src/claude_accounts.rs` + 命令 `commands/claude_accounts.rs`：

| 命令 | 作用 |
|---|---|
| `list_claude_accounts` | 列出账号：id、名称、Code 是否已登录（`code/.claude.json` 的 `oauthAccount.emailAddress` / 套餐字段；凭据文件存在）、Desktop 目录是否已初始化；附默认账号的同类信息 |
| `create_claude_account(name)` | 建目录与 `account.json`，返回账号 |
| `rename_claude_account(id, name)` | 只改显示名 |
| `delete_claude_account(id)` | 删除该账号目录（前端二次确认；Desktop 正在使用该目录时拒绝） |
| `open_claude_account_terminal(id, cwd?)` | 复用 `launch_terminal_with_env`，注入 `CLAUDE_CONFIG_DIR=<code 目录>`，未登录时提示在终端里运行 `claude` 完成登录 |
| `launch_claude_desktop_account(id)` | 以 `--user-data-dir=<desktop 目录>` 启动 Claude Desktop：Squirrel 安装直接启动 `Claude.exe`；MSIX 安装经执行别名 `claude-desktop.exe`；该账号尚未登录且已有 Claude 窗口在运行时拒绝并说明原因（登录回调走 `claude://`，会被已运行的实例接走） |

读取 `.claude.json` 用有界读取，失败当作"未登录"，从不报出文件内容。

## 4. 前端

- Claude Code 页、Claude Desktop 页各加一张「账号」卡片（与页面现有卡片同一套玻璃样式）：
  - 每行：名称、登录邮箱或「未登录」、套餐标签；操作「打开终端」/「打开 Claude Desktop」、更多菜单（重命名、删除）。
  - 「添加账号」：输入名称 → 创建 → 立即打开（Code 打开终端引导登录；Desktop 打开新窗口引导登录）。
  - 默认账号一行只读，说明"未加隔离的系统默认目录"。
- 删除确认写明会删除该账号的本地登录态与会话，且不影响默认账号。
- 文案简体中文；空状态解释"每个账号一个独立目录，登录互不影响，可同时使用"。

## 5. 暂缓（后续版本）
