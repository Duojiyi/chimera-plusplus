## 1. 线路编辑器（P3）

2.8.6 把 8 个工具的新建 / 编辑线路换到同一套组件上（`src/components/providers/ProviderEditorFields.tsx`），下面是统一后仍不一致或偏吵的地方。

- [ ] **「正在使用」提示条**：三种措辞，且都没点名写入的文件。
  - Codex / Claude Code：「保存后立即写入…；重新打开…后生效」（`src/ChimeraApp.tsx`，`inUseNote`）。
  - OpenCode / Pi：「这条线路已启用…」。
  - Grok / Claude Desktop：「保存后同步写入…」（`src/views/ToolViewEditor.tsx`）。
  - oh-my-pi 没有提示条，尽管它的编辑器已经显示「配置位置：…models.yml」。
  - 做法：统一成一句；能拿到实际路径的工具（后端已知 live 文件位置）把路径传进来，拿不到的只写工具名，不要凭空写默认路径（配置目录可以自定义）。
- [ ] **Grok Build、Claude Desktop 缺「保存详情」**：其余 6 个编辑器都有（`ToolViewEditor.tsx` / `GrokBuildProviderForm.tsx` / `ClaudeDesktopProviderForm.tsx` 中没有这一块）。做法：复用 ProviderEditor 的保存详情块，列出写入位置与协议，密钥打码。
- [ ] **新建线路的默认名称**有三种：Grok / Claude Desktop 预填「ChimeraHub」，Codex / Claude Code / Gemini / OpenCode / Pi 预填「新线路」，oh-my-pi 标题为「未命名线路」（`GrokBuildProviderForm.tsx` 约 129–131、Claude Desktop 预设、`OmpProviders.tsx` 约 387）。外观控件的文案也不同（「默认 · 自动简称」vs「默认图标」）。
- [ ] **空白的新 Claude Code 线路一打开就显示档位警告**（`ChimeraApp.tsx`，`unsetTiers`）。做法：用户动过模型字段或点过保存后再显示。
- [ ] **字段叫法**：OpenCode / Pi 用「模型 ID *」，其余用「默认模型」（`ChimeraApp.tsx` 约 6138）。改名时同步 `tests/components/PiManagement.test.tsx`、`OmpView.test.tsx`、`ChimeraApp.races.test.tsx` 里按「模型 ID」查找的用例。
- [ ] **「完整 URL」开关位置**：Grok 在地址标签右侧，Codex 的「完整 API 地址」在 高级配置 › 兼容性；「获取 API Key」链接也只有部分编辑器有。
- [ ] **Codex 模型映射的「思考等级」下拉**在 1140 宽下截断为「3 档 · …」。做法：列宽按内容或加 `title` 显示全文。
- [ ] **Claude Code 地址提示文案**：提示「…不自动追加路径」和帮助「Claude Code 在这个地址后拼接 /v1/messages」主语不同，读起来像矛盾。建议提示改为「Chimera++ 不改写这个地址；Claude Code 会在后面拼接 /v1/messages」。
- [ ] **Grok Build、Claude Desktop、oh-my-pi 的编辑页标题栏没有「删除线路」**，目前只能在列表里删。删除前的「是否为当前线路」检查在 `ToolView` 里，需要把它抽成可复用的确认流程。
- [ ] **oh-my-pi 的模型列表选择器**（`OmpModelPicker`）仍是独立控件，未换成统一的模型选择器。

## 2. 功能缺口（P3）

## 4. 导入链接脱敏的已知取舍（不改，记录在案）

- 单独写在开关后面的凭据（`--api-key VALUE`）原样显示：不知道开关带不带值时，那一项可能正是要运行的包（`npx -y --auth-token @evil/pkg`），遮住它会藏起真正运行的东西。
- 模型档位显式设成与默认模型相同的值，会被当作「跟随默认模型」。
- JSON 形式的 `--headers` 取值、只含 AUTH 的键名、多行 TOML 字符串目前不遮盖。

## 5. 开发与发布注意

- **本地调试版会抢占链接注册**：Windows 调试版启动时调用 `register_all()`（`src-tauri/src/lib.rs`，`cfg(all(debug_assertions, windows))`），把 `chimera://`、`ccswitch://` 改成指向调试版。预览前导出 `HKCU\Software\Classes\chimera`、`HKCU\Software\Classes\ccswitch`，结束后导回。可考虑让调试版在已有处理程序时跳过注册（Linux 分支已经这样做）。
- **仍需在真机确认**：Windows 上标题栏 / 侧栏顶部拖动窗口、双击最大化、标题栏按钮可点（09237ebd 改为 Tauri 事件拖拽后，CI 无法验证）。
- **偶发超时测试**：`process_utils::captures_inherited_pipe_output_after_direct_child_exit` 在 windows-2022 上因 PowerShell 冷启动超时，2.8.6 已把上限放宽到 60 秒；若再出现，说明是真问题而不是负载。
- **CSS 体积预算**：`scripts/check-bundle-budget.mjs` 的样式表上限 204,800 字节，2.8.6 为约 198,000 字节；新增样式优先复用现有类。
