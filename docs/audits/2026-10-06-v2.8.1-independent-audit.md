## 发布门禁与限制

- 遵守项目规则，本机只运行 `cargo fmt --check`，不执行 Rust 编译、测试或 Clippy，不删除 Rust 构建缓存。新增 Rust 用例的实际执行必须由同提交 GitHub Actions 结果证明。
- 先推送通过本地整合验证的提交到 main；仅在该 SHA 的三平台后端、Windows 前端及 Windows x64/ARM64 portable validation 全部成功后，才允许推送 `v2.8.1` 标签。
- 发布沿用既有资产、哈希、来源证据与更新签名验证，待 `latest.json` 完整验证后才晋升 latest。此文件不代替 GitHub Actions 的同 SHA 成功记录。
- 未覆盖所有真实第三方 API/OAuth、原生 WebView 端到端、断电恢复、完整协议流式输入、所有外部固定版本引擎实现及完整屏幕阅读器流程。macOS 手动包仍未做 Apple Developer ID 签名/公证，Tauri 更新签名不等于操作系统代码签名。
