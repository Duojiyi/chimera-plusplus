## 实现

- 应用内全页编辑，保留系统标题栏。原列表和导航保持挂载但隐藏，保留原页面状态。
- 顶部返回、中部独立滚动、底部测试和保存操作。宽屏模型表格，900px 以下双列卡片，600px 以下单列。
- 主要输入和标签 14px，说明 13px。映射不再藏于高级配置。长错误可换行。
- 返回、取消、Escape 使用同一未保存检查；非模态页面不捕获 Tab，嵌套确认框继续使用已有焦点管理。
- 保存期间锁定输入；空实际模型 ID 阻止保存并定位；允许零映射使用默认模型。
- 自动协议探测费用说明持续可见；连接测试明确只测地址连通性，不承诺密钥或模型可用。
- 恢复模板二次确认，保留草稿 ID、线路名和共享配置草稿。共享配置改回基线后不再误报修改；异步加载避免旧请求覆盖新草稿。
- 应用成功设置待重启状态；成功重启后清除。模型目录校验失败保持编辑页和持续错误，重试更新已保存线路，不重复新增。
- 不增加运行依赖。配置解析库拆入 vendor-config，保持现有入口体积预算。

## 独立审计整改

1. 模板生成新 ID 导致共享草稿重载：保留 ID，补充行为测试。
2. 非模态编辑期间标题栏关闭/更新可打断编辑：编辑期间禁用这两个应用内入口，最小化可用。
3. 窄屏思考等级仍固定四列：改 auto-fit Grid。
4. 默认思考等级缺少可访问名称：增加带模型行号标签。
5. 管理弹窗关闭后返回目标已卸载：回退到仍存在的“管理线路”入口。
6. 共享配置脏状态不准确：与加载/保存基线比较。
7. 保存后待重启状态与目录错误只短暂提示：持续状态和留页错误；复审补上成功重启清除标记。
