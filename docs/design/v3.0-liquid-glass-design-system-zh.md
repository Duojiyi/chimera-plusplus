## 0. 方向与来由

两版都被否过，这是第三版：

| 版本 | 方向 | 结局 |
|---|---|---|
| v2.8 现状 | 通用 SaaS 蓝 + 卡片边框 + 四站轨道模板复用 | 用户否：死板、无高端感、AI 味 |
| v2.9 初版 | Signage 站牌（深/浅双套、发丝线、反白选中） | 用户否：像传统工具，没有创新 |
| **v3.0（本版）** | **单一浅色 + 液态玻璃材质 + 结构优先** | 待审 |

### 0.1 液态玻璃在这里是什么

不是「半透明卡片 + 模糊」这种滤镜。玻璃只有在**底下有东西可折射**时才成立，所以：

1. **页面底是一层纵向冷灰渐变** `#e2e5e1 → #d2d6d1(0.55) → #bfc4be`（rotation 90°），不是纯白也不是纯色。白底上的玻璃看不出来；纯色底上玻璃只有一层均匀色差，看不出「浮起」。
   - 实测（CIE76）：卡片 `#f7f8f8` vs 底最暗端 → **dE 11.35**；卡片 vs 侧栏 **6.51**；侧栏 vs 底 **4.86**。上一版底太浅（侧栏与底只有 dE 1.32，等于同一层），看不出材质。
   - 另铺 **24px 极细网格**（线色 `#0b1c2a10`，实测与格心 dE 4.4；`0x07` 只有 1.9，肉眼不可见），覆盖整幅 1140 宽（含侧栏），作为折射纹理。玻璃盖上去时网格会发生可见的偏移与压暗 —— 这是唯一让静态设计稿也能读出「玻璃」的手段。
2. **不要背景光斑**。第一版用了四团 radial 渐变（蓝/紫/青绿/橙），那是 2024 年 AI 落地页的标准配方，也是「廉价感」的最大来源。已全部删除。
3. **玻璃靠三层边缘成立**，不靠 1px 描边堆层次：
   - `background_blur 30`（卡片）/ `40`（侧栏）/ `24`（内嵌控件）
   - 顶部内侧高光 `inner shadow #ffffffd9, offset (0,-1), blur 0` ← 真正让人「摸到玻璃边」的是这一层
   - 底部内侧柔光 `inner shadow #ffffffcc, offset (0,1), blur 2`
   - 外投影 `#1236681a, offset (0,10), blur 24` ← 唯一允许的投影，只给玻璃容器
4. **同一屏幕最多三层玻璃**：侧栏 / 卡片 / 卡片内嵌控件。第四层就是噪音。
5. **玻璃不叠玻璃**。卡片里放输入框，输入框是 `#0b1c2a08` 实色，不再模糊。

### 0.2 结构优先于装饰（从 v2.9 继承，未变）

- 不为「容器感」加边框；用发丝线与列节奏组织信息。
- **同一时刻只有一种饱和色**：饱和色只表达状态。选中态用中性高光 `#eef1ee` + 白色描边，不用彩色。
- **每个工具一条线路色杠**（`3×16` 或 `14×3`）作为身份标记，替代 v2.8 的 `CC/CD/Gm/OC/Pi/Om/Gk` 双字母方框（那看起来像错字）。
- 字体三分工：`Noto Sans SC`（中文与 UI）/ `Overpass Mono`（数字、域名、路径、ID、耗时）/ `Overpass`（英文标题与 wordmark）。

### 0.3 配色主张：石墨绿（用户选定，2026-11-11）

评审给的判词里最硬的一条不是布局，是**配色没有主张**——「中性灰 + 正蓝 `#0b66d0` + 白玻璃 = 任何模板都能拼的三件套」。据此做了三个只换色、不动结构的变体（图存 `docs/design/palette/`），用户选定 **B 石墨绿**：

| 版本 | 强调色 | 记忆点 | 页面底对比度 | 结局 |
|---|---|---|---|---|
| A 正蓝 | `#0b66d0` | 无 | 3.56:1（不达 AA） | 弃 |
| **B 石墨绿（采用）** | **`#1f4d3a`** | 无彩色记忆点，靠材质与结构立身 | **5.44:1** | 已刷全部画板 |
| C 墨与黄铜 | `#0c1a24` | 黄铜 `#c8a96a` 作当前行标记 | 9.97:1 | 备选（黄铜只能当装饰，2.25:1 不能当文字） |

选择 B 的工程收益：旧正蓝在页面底最暗端只有 3.56:1，因此之前被迫写下「彩色文字不得压在页面底上」这条限制；石墨绿 accent 在底上 5.44:1，主按钮/图标/链接可以自由落在底上。`ok/warn/bad` 三个状态色仍在 3.35–3.60，仍须落在卡片或侧栏之上。
**全部 44 块画板**的 accent 已批量替换（fill 190 + stroke 19 + text 76 → `#1f4d3a`），旧色残留 0；顺带把 7 种残留的蓝调浅底（`#f2f8ff`/`#eef2f7`/`#e6edf7`/`#f0f4f8`/`#c9d2dd`/`#eef1f6`/`#e2e6ec`，共 65 处）中性化为冷灰同明度值，避免「一点蓝」破坏石墨底的中性。

### 0.4 一条自我约束

**任何一个形状必须在至少三类不同数据上被复用，才允许进入设计系统。** 反例：v2.8 的「四站轨道」被当成 KPI 模板套在用量页和 Codex 管理页上，装饰大于信息 —— 本版已永久删除，唯一保留是 L04 右栏「生效后的线路」纵向推演（那是配置预览，数据可校验）。

### 1.2 语义

| 令牌 | 值 | 页面底（最暗端） | 卡片上 | 白字配它 | 唯一语义 |
|---|---|---|---|---|---|
| accent | `#1f4d3a` 石墨绿 | **5.44:1** | 8.73:1 | 9.63:1 | 主按钮、当前导航、链接、选中描边、额度 <90% |
| ok | `#0d7340` | 3.35:1 | 5.37:1 | — | **只**表达：已连接 / 已启用 / 已是最新 / 成功 |
| warn | `#8a5209` | 3.60:1 | 5.79:1 | — | 需处理但不阻断：额度 ≥90%、IPv6 不可用、无签名、路径可能写失败、延迟偏高 |
| bad | `#b4342c` | 3.42:1 | 5.49:1 | — | 失败、删除、密钥失效、登录过期、超时 |

**accent 换色带来的收益**：旧正蓝 `#0b66d0` 在页面底最暗端只有 3.56:1，因此曾被迫规定「彩色文字不得压在页面底上」。换成石墨绿 `#1f4d3a` 后 accent 在底上达 5.44:1，主按钮、图标、链接可以直接落在底上。
**仍受限制的三个**：ok / warn / bad 在页面底最暗端只有 3.35–3.60:1，**状态文字必须落在卡片或侧栏之上**；直接放在底上的只允许 `ink` / `body` / `mute` / `accent`。

**铁律三条**：
1. `ok` 绝不能用于失败次数、下降趋势、警告项。v2.9 早期把「失败 9 次」画成绿色，已修正为 `bad`。
2. `+8.2%` 这类中性增长用 `mute`，不用绿色 —— 绿色只留给「状态」。
3. 额度进度条：**条长 = 已用百分比**（不是剩余）；`<90%` 用 accent，`≥90%` 用 warn，`≥100%` 或已耗尽用 bad；`已用 0%`（停用/无数据）不取色，用 `chrome` 槽色。所有百分比文字前必须写「已用」二字，避免与「剩余」混淆。

### 2.1 字号阶梯（7 档 + 0.5 步进）

| micro | 10 / 9.5 / 9 | 列头、元信息、chip、脚注 |

行高：正文 1.55，说明 1.45，代码 1.75。
字距：h1 `-0.2px`，h2 `-0.1px`，数值 `0`。

### 2.2 尺度网格

- 窗口：**1140×816**（默认与最小），窗体圆角 **14**，无 1px 硬描边（描边交给内层玻璃高光）。
- 侧栏 **232**，标题栏 **52**。
- 内容区 924 − 26×2 = **852 可用宽**；776 − 18×2 = **740 可用高**；**安全底线 y=798**。
- 页面头（PH）恒 **44** 高；**块间距实测 27**（不是 13 —— 早期文档数字写错，以画板实测为准）。
- 页头右侧按钮组右缘 **1112**（板内 852），高 30，`padding 0 14`。
- 常用分栏：`560 + 276`（gap 16）/ `418 + 418`（gap 16）/ `274 × 3`（gap 15）/ `276 × 3`（gap 24）。
- 表格行高：**36**（紧凑，如线路列表）/ **56–66**（带副行，如会话列表）。
- 卡内边距实测 **24**（不是 19）。
- 圆角：控件 9 / 卡片 14 / 对话框 22 / chip 9 / logo 10。

### 2.3 动效

`120ms`（悬停、开关）/ `180ms`（展开、抽屉）/ `260ms`（页面切换），缓动统一 `cubic-bezier(0.22, 1, 0.36, 1)`。所有动效在 `prefers-reduced-motion` 下退化为 0ms 直切。

## 3. 组件规格

### 3.1 玻璃卡

```
fill #ffffffd0 · stroke #ffffff 1px · cornerRadius 14 · clip true
effect [
  { background_blur, radius 30 },
  { inner shadow #ffffffd9, offset (0,-1), blur 0 },   // 顶部高光
  { inner shadow #ffffffcc, offset (0,1),  blur 2 },   // 底部柔光
  { outer shadow #1236681a, offset (0,10), blur 24 },  // 唯一投影
]
```
卡头恒 **44** 高，`padding 0 19`，下方 `hairline #0b1c2a12`。卡体 `padding 19`。
卡片不透明度已从 `c4`(77%) 提到 `d0`(82%)：底加深后 77% 的卡会透出底色，白字区读起来发灰；82% 是「看得出底下有网格、但白区仍是白」的临界点。

### 3.2 按钮

| 类型 | 规格 |
|---|---|
| 主按钮 | 高 30，`padding 0 14`，底 `#1f4d3a`，字白 11/600，r9 |
| 次按钮 | 高 30，底 `#ffffffa8`，描边 `#ffffffd9`，字 `#33454f` 11/500，r9 |
| 文字按钮 | 无底，字 `#1f4d3a` 11/500；危险态字 `#b4342c` |
| 图标按钮 | 28×28，r8，hover 底 `#0b1c2a0a` |

**`active` 态统一 `scale(0.97)`**；`focus-visible` 统一 `outline 2px #1f4d3a, offset 2`（键盘可达性硬要求；静态画板不逐屏绘制，落地时由全局 CSS 注入到 `:focus-visible`）。

### 3.3 控件

- 开关：`30×17`，r9，开 `#0d7340`，关 `#0b1c2a1f`，滑块 13 白。
- 单选：`14×14`，r7，选中底 accent + 内嵌 6px 白点，未选中描边 1.5 `#b9c2ca`。
- 复选：`15×15`，r4，选中底 accent + 白色对勾。
- 进度条：高 5，r3，槽 `#0b1c2a14`，条按 1.2 规则取色。
- 分段控件：容器 `#0b1c2a0a` r9，选中项白底 r7 + 字 ink。
- 输入框：高 30，底 `#0b1c2a08`，r8，`padding 0 12`，聚焦描边 accent 1.5。

### 3.4 表格

- 列头：`mute` 10/500，行内数值列 `Overpass Mono` 右对齐。
- 行：高 36，`padding 0 19`；首列是 **`14×3` 线路色杠**（表格行实测尺寸；侧栏工具身份用竖向 `3×16`，两者不可互换）+ 名称（12/500）+ 副行（`Overpass Mono` 10 `mute`）。
- 当前行：底 `#eef1ee` + **左缘 2×36 `#0c1a24` 竖条** + 行尾白色「当前」chip（chip 底 `#ffffff` + 字 `#1f4d3a`）。**全站「当前」只有一种编码**：浅蓝底 chip + accent 字，不再有绿底或纯绿字。
- 行尾操作：**只放两个 12px 图标**（编辑、删除），色 `#454e58`，hover 变 ink。**不要三枚以上**。
- 行内主动作（切换 / 重新登录）若必须出现，用 22 高 ghost 文字按钮放在操作图标左侧，不与图标同列。
- 表格列数**不超过 5**。v2.9 早期的 7 列（线路/认证/协议/模型/延迟/操作）已删「认证」「协议」两列。
- **同一张表里所有数值列的 x 与 width 必须一致**（L38 曾出现五个额度槽右端横跨 52px）。

### 3.5 状态四态

| 态 | 视觉 | 必须有 |
|---|---|---|
| 空 | 图标 32 `#1f4d3a` + 一句说明 + 一个主按钮 | 出口动作 |
| 加载 | 4 行骨架，`#0b1c2a0a` r6 | 保留标题与列头，不要整屏 spinner |
| 错误 | `bad` 图标 + 一句人话 + 「详情」折叠 + 重试 | 可复制的错误码 |
| 超时 | `warn` + 已等待时长/上限 + 取消 | 明确的下一步 |

**禁止**在状态页里显示 Rust panic 原文、SQL 语句、内部线程名。

## 7. 反模式（10 条，违反即退回）

1. **不要背景光斑**。四团低饱和 radial 渐变 = AI 落地页配方。
2. **不要装饰性渐变**。唯一例外：无。logo 和头像都是单色（`#0c1a24` / `#e6eaec`）。
3. **不要卡片套卡片套卡片**。最多三层（页面 → 卡 → 控件）。
4. **不要给卡片/按钮/文字加投影**。唯一投影是玻璃卡的外投影。
5. **不要一色多义**。同一个色值只能有一个语义。
6. **不要用成功色画失败**。
7. **不要四列以上表格**。
8. **不要在状态页泄露内部实现**（Rust panic、SQL、线程名、`wire_api`、`history.persistence`）。
9. **不要装饰性控件**（信号条、扫描环、地图、霓虹、进度环）。
10. **不要推广位、返利链接、赞助 banner、皮肤市场入口**。
