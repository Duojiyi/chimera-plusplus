1

从微软商店下载安装 ChatGPT

OpenAI 已把 Codex 桌面端合并进 ChatGPT 应用。先装好它，后面用 Chimera++ 切换中转站线路时才有地方生效。

1.1 打开微软商店并搜索 Microsoft Store

  1. 点击 Windows 任务栏底部的「Microsoft Store」图标（橙色购物袋），或在开始菜单搜索「商店」。
  2. 在商店顶部搜索框输入 ChatGPT 并回车。
  3. 认准发布者为 OpenAI 的「ChatGPT」条目（分类多为「开发人员工具」），点进去。
💡提示：也可以直接打开商店网页版 https://apps.microsoft.com/detail/9nt1r1c2hh7j，点「获取」后会自动唤起商店应用安装。

1.2 安装并打开 先完成这一步

  1. 点击「获取 / 安装」按钮，等待下载完成（约 100+ MB）。
  2. 安装完成后，从开始菜单或商店页的「打开」启动 ChatGPT。
  3. 按提示用你的 ChatGPT 账号登录（邮箱或扫码均可）。
  4. 登录后即可使用对话；Codex 已集成在同一个应用里，不必再单独装。
🛡️说明：官方账号登录与后面要用的中转站密钥是两套独立线路。官方登录后可在 Chimera++ 里选「官方账户」；想用 ChimeraHub 时切到你添加的中转站线路即可，互不干扰。
2

从哪里获取密钥

密钥（API Key）是你的「身份凭证」。Chimera++ 需要它来调用中转站。下面以 ChimeraHub 为例，只需几分钟。

2.1 打开控制台并注册账号 第 1 次使用

  1. 在浏览器打开 https://api.chimerahub.org/console（即官网右上角的「进入控制台」）。
  2. 页面会跳转到登录页，点击「没有账号？注册」链接。
  3. 按提示填写邮箱、用户名和密码，完成注册；必要时完成页面底部的人机验证。
  4. 注册后回到登录页，用刚注册的账号登录。
💡提示：中转站按用量计费，登录后如需使用，请先到「钱包」充值或兑换额度（余额可退，失败的请求不扣费）。

2.2 创建 API 密钥并复制 核心操作

  1. 登录后进入控制台「概览」页，可直接点金色按钮「创建 API 密钥」；也可在左侧菜单点「API 密钥」。
  2. 在 API 密钥页右上角点击「+ 创建 API」，给密钥起个名字（例如 Chimera++）。
  3. 提交后会出现「成功创建了 1 个 API 密钥」提示，列表里会多出一行。
  4. 在「API 密钥」列找到以 sk- 开头的密钥，点击旁的复制图标，保存好整串密钥。
⚠️重要：密钥等于你的「钱包钥匙」，不要发给任何人，也不要贴到网上或写进公开代码里。密钥泄露请立即在控制台禁用/删除该密钥并重新创建。
3

怎么复制粘贴

打开 Chimera++，把第 2 步复制的密钥粘贴进「添加线路」表单，30 秒完成。

3.1 打开添加线路表单

  1. 启动 Chimera++，底部导航默认停在「供应商」页。
  2. 在「线路切换」区域，任选其一：
    • 点最右侧的「添加线路」卡片（红色 ＋）；或
    • 点「管理线路 →」，再在弹窗底部点「+ 添加线路」。

3.2 粘贴密钥并确认地址 核心操作

  1. 右侧会弹出「新线路」面板。若显示「Chimera 中转站默认模板」，地址和默认模型已预填，一般只需粘贴密钥。
  2. 在「API Key」输入框点击，按 Ctrl + V（或右键 → 粘贴）把第 2 步复制的 sk- 密钥粘贴进去。
  3. 确认「API 请求地址」为 https://api.chimerahub.org/v1（模板已填好时不用改）。
  4. 「默认模型」可保持预填值，或点「获取模型」从列表里选一个。
  5. 「线路名称」可改成你认得的名字（例如 ChimeraHub），也可先用默认的「新线路」。
💡提示：选用 Chimera 中转站模板时，官网链接与 API 请求地址会自动填好。只有在你换了别的中转站时，才需要手动改这两个地址。

3.3 测试连接并保存 完成

  1. 点击「测试连接」，稍候应显示连接成功。
  2. 再点「保存并应用」——线路会写入 Codex，并自动切到这条新线路。
  3. 回到主页「线路切换」，确认你的新线路处于选中状态（高亮卡片）。
  4. 点击「启动 Codex」（若已在运行则点重启/重新启动），让配置生效。
✅完成！现在打开第 1 步安装的 ChatGPT / Codex 即可使用。配置保存在本机 ~/.codex/，Chimera++ 只负责帮你写入与切换线路。

常见问题

粘贴后提示「API Key 无效」？

检查两点：① 复制的密钥是否完整（以 sk- 开头、末尾没有多余空格）；②「API 请求地址」是否为 https://api.chimerahub.org/v1（不是不带 /v1 的域名）。

连接测试成功，但 Codex 里用不了？

确认第 1 步已安装并打开过 ChatGPT。切换线路后必须重新启动 Codex 才会读取新配置——回到 Chimera++「供应商」主页，点「启动 Codex」即可。

余额 / 用量在哪里看？

ChimeraHub 的余额在控制台左侧「钱包」查看与充值；概览页右侧也会显示剩余额度。Chimera++ 的「词元」页可查看请求与词元统计。

想用官方 ChatGPT 账号，不想要中转站？

在 Chimera++「线路切换」里选「官方账户」（ChatGPT 官方登录），按提示用浏览器完成登录即可，全程不需要 API Key。想用 ChimeraHub 时切回你添加的中转站线路即可，两者互不干扰。
